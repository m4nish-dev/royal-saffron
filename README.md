# 🍽️ Royal Saffron

A luxury fine-dining restaurant website built using React and Vite.

## ✨ Features

- Modern Luxury Restaurant UI
- Fully Responsive Design
- Animated Hero Section
- Smooth Scroll Navigation
- Signature Dishes Showcase
- Meet Our Master Chefs Section
- World Cuisine Section
- Luxury Gallery
- Reservation Form
- Hover Effects & Animations
- Framer Motion Integration

## 🛠️ Tech Stack

- React.js
- Vite
- CSS3
- Framer Motion
- JavaScript (ES6)

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/royal-saffron.git
```

Move into the project folder:

```bash
cd royal-saffron
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

## 📦 Build Project

```bash
npm run build
```
